The ADE CLI is a terminal-first tool that drives LandingAI's Agentic Document Extraction (ADE) v2 APIs — parse, extract, and inspect documents from a single self-contained binary. It ships with a one-line install, built-in self-update, interactive or headless auth, a local job store that skips repeat work, and a self-describing `ade help --json` surface that lets coding agents drive it with zero setup.
